# Simple Profit Analysis

## Project Overview
This project analyzes profit across different product categories using Microsoft Excel.

## Objectives
- Compare total profit across product categories.
- Understand basic profitability.
- Identify the most profitable category.

## Tools Used
- Microsoft Excel

## Dataset
A practice dataset containing 60 sales records across:
- Furniture
- Office Supplies
- Technology

## Analysis Performed
- Total Sales
- Total Cost
- Total Profit
- Average Profit
- Category-wise profit comparison

## Excel Functions
- SUMIF
- AVERAGEIF
- Basic arithmetic formulas

## Visualization
A bar chart comparing total profit across product categories.

## Deliverables
- Excel workbook with raw data.
- Profit summary.
- Category-wise profit chart.

## Conclusion
The analysis provides a simple understanding of profitability and demonstrates how Excel can be used to summarize and visualize business data.
